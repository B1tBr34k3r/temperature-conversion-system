01. The Problem Space

Why Scientific Temperature Conversion is Broken

Conventional temperature tools treat conversion as trivial arithmetic, leading to compounding errors in scientific, educational, and laboratory contexts.

Floating-Point IEEE-754 Drift

Repeated binary arithmetic causes cumulative precision decay (e.g. 0.1 + 0.2 = 0.30000000000000004), corrupting scientific sensor readings.

Physical Boundary Violations

Standard converters permit inputs below Absolute Zero (-300 °C or -10 K), breaking foundational thermodynamic laws.

O(N²) Formula Explosion

Pairing 8 scales directly requires 56 unique mathematical formulas, creating maintenance nightmares and uneven precision tolerances.

02. Architectural Solution

3-Tier Enterprise Decoupled Model

Clean separation of concerns guarantees that mathematical computation is isolated from UI presentation and database persistence.

Presentation Tier (SPA)

Tactile modern web UI with CSS design tokens, dynamic canvas ray visualizer, and Web Audio API synthesizer. Zero heavy frontend frameworks required.

Business Logic Tier (Express API)

Modular Node.js 20 backend with strict input validation, canonical Kelvin routing, step-by-step formula derivation, and diagnostic /api/health.

Persistence Tier (SQLite 3 WAL)

ACID-compliant relational database operating in Write-Ahead Logging mode with B-Tree indices on timestamp and scale pairs. Streaming CSV/JSON export.

03. Algorithmic Core

Canonical Kelvin Pivot: O(2N) Scaling

Every conversion routes through the SI thermodynamic base scale (Kelvin), shrinking algorithmic complexity from 56 equations to 16 clean transformations.

8 Supported Scales

Celsius, Fahrenheit, Kelvin, Rankine, Delisle, Newton, Réaumur, and Rømer. Immediate uniform precision across all historical and SI units.

56-Vector Inverse Symmetry

Every transformation satisfies $f^{-1}(f(x)) = x$ within strict epsilon tolerance ($\le 10^{-9}$), mathematically proven across 56 round-trip permutations.

Absolute Zero Interception

Strict physical validation intercepts any entry $< 0\text{ K}$ prior to arithmetic or persistence, enforcing the Third Law of Thermodynamics.
